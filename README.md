# Peanut Admin Core PHP

`peanut-admin/core` 的 PHP 源码仓。它包含可复用的 PHP Runtime、Kernel、Settings、Tenant、权限、任务、文件与相关模块。

日常开发使用 `dev`；`main` 只承载已批准的发布版本。该仓在 2026-09-17 从原 Core 单体仓的 `packages/php` 拆出，初始开发提交为 `d1c25fdd3bc27cc8bd56fcaa2d4cbdc33c906bbe`。

发布工作流尚待从旧仓迁移和资格确认。在此之前，现有 Composer 发布标签仍是历史事实，不应将本仓的开发分支视为已发布包。
